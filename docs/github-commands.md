# GitHub Commands

```bash
git init
git add .
git commit -m "Initialize cloud assignment portal"
git branch -M main
git remote add origin <YOUR_GITHUB_REPOSITORY_URL>
git push -u origin main
```

Continue with:
```bash
git add . && git commit -m "Create frontend and backend architecture"
git add . && git commit -m "Implement authentication and role management"
git add . && git commit -m "Add assignment management module"
git add . && git commit -m "Integrate cloud database"
git add . && git commit -m "Implement cloud file storage"
git add . && git commit -m "Add student assignment submission workflow"
git add . && git commit -m "Implement deadline validation"
git add . && git commit -m "Add teacher grading and feedback"
git add . && git commit -m "Build student and teacher dashboards"
git add . && git commit -m "Add security and authorization"
git add . && git commit -m "Add automated tests"
git add . && git commit -m "Deploy application to cloud"
git add . && git commit -m "Complete README and documentation"
```

Before pushing, verify `.env`, databases, uploads, credentials and service-role keys are ignored.
